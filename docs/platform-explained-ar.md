# شرح المشروع

## من الكود لحد المستخدم

المشروع فيه تطبيق Go وتطبيق Node.js. كل تطبيق بيتبني كصورة container. GitHub Actions يبني الصورة ويشغّلها ويختبر health وversion وmetrics، وبعد نجاح الاختبار ينشر نفس الصورة. بعدها يتحدث رقم الصورة في Helm values داخل Git. Argo CD يلاحظ التغيير ويحدّث Kubernetes. كده نقدر نعرف أي commit أنتج الصورة، وأي values اختارت الإصدار اللي شغال.

Helm هو قالب الموارد: Deployment لتشغيل النسخ، Service للوصول ليها، HPA لزيادة العدد حسب الحمل، وPDB لتحديد الحد الأدنى أثناء الصيانة. عندنا الحد الأدنى ثلاثة، والتوزيع حسب hostname يقلل تجمع النسخ على نود واحدة. PDB ينظم الإخلاء الاختياري؛ مش ضمان إن الأعطال المفاجئة مستحيل توقف خدمة.

## التلات نودز

كل نود عندها دور control-plane ودور worker. API server يستقبل أوامر Kubernetes، scheduler يختار مكان الـPod، وcontrollers يتابعوا إن العدد والحالة يطابقوا المطلوب. kubelet ينفّذ تشغيل الـPods على نودته باستخدام containerd.

etcd يخزن حالة Kubernetes. عندنا ثلاثة أعضاء، والقرار محتاج أغلبية اتنين. عضو واحد ممكن يقع وتفضل الأغلبية؛ توقف اتنين يضيّع quorum. etcd مش بيخزن ملفات Grafana ولا تاريخ Prometheus، ولذلك نسخة etcd الاحتياطية لوحدها مش نسخة احتياطية لكل المشروع.

العناوين .178 و.181 و.182 تخص النودز. العنوان .179 مش نود رابعة؛ ده عنوان الخدمات المشترك. أسماء النودز محفوظة في inventory مع الأدوار ورقم VM عشان الأوديت يبقى واضح.

## الشبكة والوصول

Cilium بديل Flannel. بيدي Pods عناوين من 10.245.0.0/16، وينقل المرور بين النودز عبر VXLAN، وينفّذ NetworkPolicy. kube-proxy ما زال مسؤول عن توجيه Services. Hubble يساعدنا نشوف التدفقات والمرور المرفوض.

السياسة المضافة تخص التطبيقين: تسمح بدخول Traefik ومراقبة Prometheus والتواصل بين التطبيقات، وتسمح بخروج DNS والاتصالات المحددة للتطبيقات. أي خروج مختلف يتمنع للـPods المختارة. نجاح فتح الموقع وحده مش كفاية لاختبار السياسة؛ اختبرنا كمان DNS واتصال مسموح واتصال مرفوض.

MetalLB يعلن عنوان .179 على الشبكة. Traefik يستقبل HTTPS ويختار الخدمة حسب الدومين. cert-manager يصدر ويجدد الشهادات. منفذ 6443 يمرر اتصال Kubernetes API كما هو لواحد من ثلاثة API servers، مع فحص TCP للصحة. شهادة وهوية API تفضل مسؤولية Kubernetes.

كان فيه اعتماد دائري عند بدء التشغيل: Cilium محتاج API عن طريق Traefik، وTraefik محتاج شبكة Cilium عشان يقوم. الحل إن Cilium وkubelet يكلموا API المحلي للنود وقت البداية. بعد قيام الشبكة العنوان المشترك يخدم العملاء الخارجيين.

## Argo CD وTerraform

Argo CD يقارن Git بالحالة الفعلية ويعمل reconciliation. app-of-apps يدير تطبيقات فرعية للتطبيقات والمراقبة والسياسات ومكونات المنصة. النسخة HA فيها اتنين server واتنين repo-server وثلاثة Redis وثلاثة HAProxy. مش كل مكون فيها اتكرر؛ controller وDex وبعض controllers لسه نسخة واحدة حسب إعداد upstream.

Terraform يدير releases البنية التحتية. ملف state يربط المورد في الكود بالمورد الحقيقي. لازم نستورد release موجود بالفعل قبل استخدام state جديد؛ مجرد وجود كوده مش معناه Terraform عارف إنه موجود. plan مهم قبل apply، خصوصًا لمكونات الشبكة.

Sealed Secrets يسمح نحفظ السر مشفرًا في Git، والـcontroller داخل الكلاستر يفكه بالمفتاح الخاص. public certificate ممكن يكون في الريبو؛ المفتاح الخاص وkubeconfig وكلمات المرور وjoin tokens ماينفعش يتنشروا.

## المراقبة

node-exporter يجمع معلومات نظام كل نود. kube-state-metrics يعرض حالة موارد Kubernetes. Prometheus يسحب metrics ويقيّم قواعد التنبيه، Grafana يعرضها كلوحات، وAlertmanager يدير إرسال التنبيهات. metrics-server مختلف: يوفر معلومات CPU والذاكرة اللحظية للـHPA وkubectl top.

Prometheus بيراقب النودز الثلاث، لكنه نفسه نسخة واحدة. Prometheus وGrafana وAlertmanager بيستخدموا PVCs على Longhorn، والـvolumes الثلاثة حاليًا Bound وHealthy ومكررة على عقد الكلاستر. النسخ الثلاث بتحسن توافر التخزين، لكنها مش بديل عن نسخة احتياطية خارج الكلاستر.

Grafana بيحوّل غير المسجل لصفحة الدخول. Prometheus عليه Basic Auth و401 بدون بيانات الدخول طبيعي. نقيس صحة الخدمة منفصلة عن تسجيل الدخول، وما نلغي الحماية عشان الـURL يرجع 200.

## قراءة نتيجة الاختبارات

CI يفحص YAML وTerraform وقوالب Helm وschemas والكود اللي يدقق العناوين والتوزيع والسياسات. الاختبارات دي تمنع أخطاء قبل النشر، لكنها ما تثبتش وحدها إن شبكة حقيقية أو تخزين حقيقي يتحمل كل عطل. بعد النشر نراجع Ready وArgo Healthy وAPI والمواقع وscrape targets، ومع الصيانة نختبر نود واحدة كل مرة ونحافظ على quorum.
