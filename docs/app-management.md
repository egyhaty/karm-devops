# إدارة تطبيقات المنصة

## الشروحات: الحسابات والمتعلمين

- الصفحة الرئيسية: [learn.murabba.net](https://learn.murabba.net/).
- الإدارة: [learn.murabba.net/admin](https://learn.murabba.net/admin).
- ادخل بحساب الموقع المعتاد الذي يحمل صلاحية Administrator. رابط الإدارة يعيدك إليها بعد تسجيل الدخول.
- اللوحة تعرض المستخدمين، تقدم الجولة التمهيدية، أعداد الحسابات، وسجل تغييرات الصلاحيات. تقدر تمنح صلاحية أدمن لحساب آخر أو توقف حسابًا.
- إنشاء أول أدمن أو إعدادات الهوية المتقدمة يتم عبر Keycloak، بالخطوات الموجودة في `golang/docs/PROJECT.md`. اللوحة ليست مفتوحة لكل حساب مسجل، ولا يوجد لها باسورد عام مشترك.

## الشروحات: المحتوى والتصميم

اللوحة الحالية ليست CMS؛ إضافة الدروس وتعديلها يتم من Git:

1. عدّل ملفات Markdown في `golang/content/lessons/`.
2. لو بتضيف درسًا، ضيف بياناته في `golang/content/catalog.json`.
3. من `golang/content/` شغّل `npm ci` ثم `npm test` ثم `npm run build`، وراجع الصفحات الناتجة.
4. احفظ تغييرات المصدر والملفات الناتجة في commit وارفعها عبر مسار العمل المعتاد.
5. GitHub Actions يبني الصورة ويختبرها ويحدّث إصدار Helm. تطبيق `golang` مضبوط حاليًا على مزامنة يدوية في Argo CD؛ بعد نجاح البناء افتح التطبيق واعمل Sync لتطبيق الإصدار الجديد.

التصميم العام للمكتبة في `golang/web/reference.css`، والصفحة الرئيسية في `golang/web/index.html`. ألوان الموقع المشتركة في `golang/web/theme.css` ويستخدمها أيضًا تصميم الجولة القديمة. الجولة التمهيدية في `/course.html`، ورابط `/library.html` القديم يحوّل للرئيسية.

## العقارات: إدارة المحتوى والطلبات

- الموقع: [makan.murabba.net](https://makan.murabba.net/).
- لوحة الوكيل: [makan.murabba.net/admin.html](https://makan.murabba.net/admin.html).
- افتح ملف الاعتماد المحلي `.backup-recovery/makan-credentials.env` وخد **قيمة `admin-token` فقط**، بدون اسم المفتاح أو علامة `=`. الصقها في خانة Administrator access token واضغط Open workspace.
- الملف محلي، مستبعد من Git، وصلاحياته للمالك فقط. لا تنشره أو تضع محتواه في commit. انقل القيم إلى مدير كلمات المرور الخاص بك.
- تقدر تضيف عقارًا بالعنوان والموقع والنوع والسعر والمساحة والغرف والوصف، وتشوف آخر 100 طلب معاينة وتحوّل الحالة بين `new` و`contacted` و`closed`.
- مفتاح اللوحة يظل في ذاكرة التبويب فقط؛ تحديث الصفحة أو Lock workspace يتطلب إدخاله مجددًا. حسابات الـ learning منفصلة عن مفتاح إدارة العقارات في النسخة الحالية.
- البيانات تُحفظ في PostgreSQL وتظهر لكل نسخ التطبيق. تعديل seed داخل الكود لا يعدّل العقارات الموجودة بالفعل.

النسخة الحالية **لا تدعم** تعديل/حذف العقار الموجود أو رفع صور من اللوحة. تستخدم رسومات توضيحية محلية، ولا ترسل بريدًا أو SMS. تلك إمكانيات لاحقة وليست أزرارًا مخفية في الإدارة.

## تشغيل التطبيقين

- [Argo CD](https://argocd.murabba.net/): إصدارات النشر، حالة المزامنة، صحة الموارد، وفشل التشغيل. `nodejs` يتزامن تلقائيًا، و`golang` يدوي حاليًا.
- [Grafana](https://grafana.murabba.net/): مراقبة الطلبات والأخطاء والموارد.
- [GitHub Actions](https://github.com/egyhaty/karm-devops/actions): نتائج الاختبارات والبناء وفحص الصور والترقية وفحوصات ما بعد النشر.
- إعدادات نسخ وموارد العقارات في `charts/values-node.yaml`، وإعدادات الشروحات في `golang/deploy/chart/values.yaml`. عندما يكون HPA مفعّلًا، اضبط حدوده الدنيا والعليا بدل تغيير replicas يدويًا.
- غيّر الإعدادات من Git ثم Argo CD، لأن التغييرات المباشرة قد تُستبدل بالحالة المسجلة في Git.
- النسخ الاحتياطي والاستعادة موضّحان في `docs/storage-and-recovery.md`. استعادة قاعدة بيانات تغيير مستقل يحتاج اختبارًا وخطة واضحة، وليس مجرد Rollback لصورة التطبيق.
