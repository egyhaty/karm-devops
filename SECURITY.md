# Security Policy

## Scope

This repository is a portfolio and learning project. Please report suspected credentials, vulnerable configuration, or security issues responsibly.

## Reporting

Do not publish secrets or exploit details in a public issue. Contact the repository owner privately through the contact information on the GitHub profile, including:

- A short description of the issue.
- Affected file or component.
- Reproduction steps, if safe.
- Suggested mitigation.

## Credential exposure

If you find a token, password, private key, or other credential, treat it as compromised and report it privately. The credential should be revoked or rotated before any public cleanup.

## Supported state

This project is maintained as time permits. Security reports are reviewed on a best-effort basis.
