# إعداد مساعد كارم

الحالة: تجهيز فقط. لا يوجد بوت شغال أو حسابات مربوطة أو جدول آلي مسجل.

## المسارات الستة

| المسار | الاستخدام | المخرج |
|---|---|---|
| الوظائف | دور على فرص تناسب خبرتي أو قيّم إعلان | مصدر وتاريخ ورابط، شروط فعلية، ملاءمة بأدلة، فجوات، مسودة رد، سجل متابعة |
| المعرفة والمذاكرة | فهم موضوع، لاب، مراجعة أو احفظ حل | شرح حسب مستواك، تمرين، تصحيح، سجل تقدم، ملاحظات بمصادر |
| الشخصي | نظم يومي وأولوياتي | مهام قابلة للتنفيذ، مواعيد بمنطقة زمنية، ملخص للحاجات المفتوحة |
| التذاكر | حلل تذكرة ولوج وجهز رد | أعراض وأدلة، فرضيات، خطوات فحص، رد إنجليزي من غير ادعاء تنفيذ |
| البنية التحتية | حلل مشكلة كوبرنيتس أو لينكس | تأثير، نطاق، فحص محدود، تفسير، اقتراح إصلاح ورجوع وتحقق |
| كودكس | حول طلب لتغيير في المشروع | تكليف محدد، خطة داخل الريبو، تشغيل sandbox عند التفعيل، diff ونتائج اختبارات |

## أمثلة استخدام

- «دورلي على وظائف Linux / Cloud / DevOps في دبي تناسب خبرتي، واستبعد المكرر».
- «الإعلان ده مناسب ليا؟ افصل المطلوب اللي عندي عن اللي محتاج أتعلمه».
- «اشرحلي IAM role وبعدين لاب واختبرني في سيناريو عملي».
- «احفظ حل مشكلة WordPress Toolkit كإجراء، متعممش chmod على ملفات غلط».
- «رتب أسبوعي مع شيفتات السبت والحد والاتنين؛ خلّي النوم قبل المذاكرة».
- «حلل رسالة Exim دي، واديني رد عميل بالإنجليزي».
- «الـPod بيعمل restart؛ دي الـevents والـlogs، حللهم».
- «جهز تكليف لكودكس يضيف درس AWS في المشروع مع الاختبارات المناسبة».

## قرارات التصميم

واجهة Telegram خاصة بصاحب الحساب. مساعد واحد بمهارات متعددة، مش ستة خدمات بتستهلك ستة اشتراكات. الذاكرة المختصرة تفضيلات وحقائق قليلة؛ السجلات التفصيلية في SQLite على تخزين دائم. تشغيل Kubernetes بنسخة واحدة، بدون منافذ عامة أو Ingress في البداية.

البحث الوظيفي يستخدم صفحات الشركات والمصادر المتاحة؛ لا يوجد ضمان وصول لـLinkedIn أو تجاوز تسجيل الدخول. الإيميل والتقويم والتذاكر وPrometheus يحتاجوا بيانات الاتصال والصلاحيات الفعلية؛ الـskills وحدها لا تعمل تكاملًا.

التجهيز يشمل كل المسارات؛ التفعيل يتدرج حسب اكتمال التكامل واختبارات حقيقية. حاليًا نقدر نجرب أدوات الحفظ والتهيئة محليًا. جودة الردود والأبحاث وتشغيل Codex داخل الحاوية تحتاج اختبار بعد اختيار الموديل وتسجيل الدخول.

## معلومات مطلوبة عند التفعيل

1. مزود الموديل والموديل وطريقة الدخول وسقف الإنفاق؛ لا ترسل المفاتيح في الشات.
2. Telegram bot token وnumeric user ID داخل Secret، لا داخل git.
3. صورة مبنية ومثبتة بـdigest، StorageClass ونوع التخزين وحالة النسخ الاحتياطي.
4. نسخة حديثة معتمدة من السيرة الذاتية قبل تجهيز طلبات فعلية.
5. الريبو ومساره والتكاملات التي تريد إضافتها فعلًا.
